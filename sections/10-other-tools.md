Other tools exist, by the way.
And more tools come into being as we speak.
So to be honest these predictions are a bit silly.
What if a new tool is published next week that takes the market by storm?
Here are two newer tools that I found interesting.

---

## Jujutsu (or `jj`)

A new, experimental version control system that features:

* the ability to use the Git or Mercurial format as a storage layer <!-- .element: class="fragment fade-in-then-semi-out" -->
* anonymous branching <!-- .element: class="fragment fade-in-then-semi-out" -->
* automatic recording of file changes <!-- .element: class="fragment fade-in-then-semi-out" -->
* undo feature <!-- .element: class="fragment fade-in-then-semi-out" -->
* advanced automatic conflict resolution <!-- .element: class="fragment fade-in-then-semi-out" -->

[github.com/martinvonz/jj](https://github.com/martinvonz/jj)

note:
Jujutsu is v0.39 and not yet feature-complete.
Its documentation states it will probably face a few breaking changes in the future.

---

## git-branchless

A usability layer on top of git that adds:

* anonymous <!-- .element: class="fragment fade-in-then-semi-out" --> branching
* user-friendly <!-- .element: class="fragment fade-in-then-semi-out" --> commands like `git undo` `git next` & `git prev`
* a commit visualization tool <!-- .element: class="fragment fade-in-then-semi-out" --> called the 'smartlog'

[github.com/arxanas/git-branchless](https://github.com/arxanas/git-branchless)
